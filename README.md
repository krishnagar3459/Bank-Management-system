# Bank-Management-system

Bank Management System 💳

A simple Bank Management System built using C++ that allows users to manage bank accounts and perform basic banking operations through a console-based interface.

🚀 Features

* Create Bank Accounts: Enter customer details, account number, PIN, account type, and balance.
* Display Account Details: View customer and account information.
* Update Account Details: Modify account information such as name, account type, initial balance, and current balance.
* Delete Bank Accounts: Remove an account from the current program session.
* Withdraw Money: Withdraw money after account verification, PIN validation, and balance checking.
* Deposit Money: Deposit money after PIN validation.
* Transfer Money: Transfer money between two different accounts.
* Account Search: Find an account using its account number.
* File Handling: Save account details in a text file.

🛠️ Technologies Used

* Language: C++
* Concepts: Object-Oriented Programming (OOP), Classes, Objects, Vectors, Functions, and File Handling
* Libraries: iostream, vector, string, cstdio
* bank_management.cpp — Contains the main program and banking operations.
* bank_data.txt — Stores account details generated by the program.
* README.md — Project documentation.

▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Compile the C++ source file using a C++ compiler.
4. Run the compiled executable.
5. Follow the on-screen instructions to perform banking operations.
